NumPy Learning Journey
A hands-on repository documenting my journey of learning and practicing
NumPy, Python's powerful library for numerical computing and
array-based data analysis.

As a BSc (Hons) Computer Science with AI student, I am strengthening
my Python fundamentals and building a foundation for Data Science,
Machine Learning, and Artificial Intelligence.
What I Have Learned
1. Array Fundamentals
- Creating arrays with np.array(), np.zeros(), np.ones(),
  np.full(), np.arange(), np.linspace(), and np.eye()
- Understanding array dimensions, size, shape, and data types with
  ndim, size, shape, and dtype
2. Indexing, Slicing, and Modification
- Accessing and updating array elements
- Selecting rows and columns from 2D arrays
- Reshaping, flattening, and transposing arrays
3. Mathematical and Arithmetic Operations
- Performing addition, subtraction, multiplication, and division
- Using functions such as np.abs(), np.sqrt(), and np.square()
- Applying element-wise operations to 1D and 2D arrays
4. Aggregation and Statistical Analysis
- Calculating sum(), mean(), median(), min(), and max()
- Using std() to calculate standard deviation
- Working with percentile(), argmin(), and argmax()
- Performing row-wise and column-wise calculations with axis
5. Random Number Generation
- Using np.random.default_rng()
- Generating random integers and floating-point numbers
- Making random selections and producing reproducible results
6. Sorting and Unique Values
- Sorting arrays in ascending and descending order
- Sorting 2D arrays row-wise and column-wise
- Finding unique values with np.unique() and counting them with
  return_counts=True
7. Filtering and Conditional Operations
- Using Boolean masking and conditional filtering
- Applying comparison operators and multiple conditions
- Selecting or replacing values with np.where()
8. Broadcasting and Vectorization
- Understanding scalar, row-wise, and column-wise broadcasting
- Learning NumPy broadcasting rules
- Performing vectorized calculations and comparing them with
  loop-based approaches
9. Array Manipulation
- Combining arrays with np.concatenate()
- Practicing array splitting
- Manipulating array structure to organize data for calculations
