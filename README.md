# 🔢 NumPy Learning Journey

A hands-on learning repository focused on **NumPy**, featuring Python code examples, practice exercises, and notes on array creation, indexing, slicing, mathematical operations, statistical analysis, random number generation, sorting, filtering, broadcasting, vectorization, and array manipulation.

As a BSc (Hons) Computer Science with AI student, I am strengthening my Python programming and numerical computing skills to build a solid foundation for Artificial Intelligence**.

## 🎯 Learning Objectives

- Understand NumPy arrays and their core properties.
- Create and manipulate one-dimensional (1D) and two-dimensional (2D) arrays.
- Perform indexing, slicing, and array modification.
- Apply mathematical and arithmetic operations.
- Perform statistical calculations and aggregation.
- Generate random numbers and reproduce results.
- Sort arrays and analyze unique values.
- Filter data using Boolean masking and conditional operations.
- Understand broadcasting and vectorized computation.
- Combine, split, reshape, and transpose arrays.

## 📚 Topics Covered

### 1. Array Fundamentals and Properties

- Creating arrays using `np.array()`.
- Initializing arrays using `np.zeros()`, `np.ones()`, and `np.full()`.
- Generating sequences with `np.arange()` and `np.linspace()`.
- Creating identity matrices using `np.eye()`.
- Understanding `ndim`, `size`, `shape`, and `dtype`.
- Working with 1D and 2D arrays.

### 2. Indexing, Slicing, and Modification

- Accessing and updating array elements.
- Selecting specific rows and columns.
- Extracting data using indexing and slicing.
- Reshaping arrays with `reshape()`.
- Flattening arrays with `flatten()`.
- Transposing arrays using `transpose()` and `.T`.

### 3. Mathematical and Arithmetic Operations

- Performing addition, subtraction, multiplication, and division.
- Applying element-wise operations to arrays.
- Using `np.abs()`, `np.sqrt()`, and `np.square()`.
- Working with mathematical operations on 1D and 2D arrays.

### 4. Aggregation and Statistical Analysis

- Calculating `sum()`, `mean()`, `median()`, `min()`, and `max()`.
- Measuring variation using `std()`.
- Calculating percentiles with `np.percentile()`.
- Finding minimum and maximum element positions using `np.argmin()` and `np.argmax()`.
- Performing row-wise and column-wise calculations using `axis`.

### 5. Random Number Generation

- Creating random number generators using `np.random.default_rng()`.
- Generating random integers and floating-point numbers.
- Selecting random elements from arrays.
- Using seeds for reproducible random results.

### 6. Sorting and Unique Values

- Sorting arrays using `np.sort()`.
- Sorting 1D arrays in ascending and descending order.
- Sorting 2D arrays row-wise and column-wise.
- Identifying unique elements with `np.unique()`.
- Counting occurrences using `return_counts=True`.

### 7. Filtering and Conditional Operations

- Filtering elements using Boolean masks.
- Applying comparison operators.
- Combining multiple conditions.
- Selecting values based on specific criteria.
- Using `np.where()` for conditional selection and replacement.

### 8. Broadcasting and Vectorization

- Understanding NumPy broadcasting rules.
- Performing scalar broadcasting.
- Applying row-wise and column-wise broadcasting.
- Carrying out calculations without explicit Python loops.
- Comparing vectorized operations with loop-based calculations.
- Creating multiplication tables using broadcasting.

### 9. Array Manipulation

- Combining arrays using `np.concatenate()`.
- Splitting arrays using `np.split()`.
- Reshaping and reorganizing array dimensions.
- Manipulating arrays for numerical calculations and data processing.
